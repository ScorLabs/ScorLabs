# SCOR Labs official website

Static official site for `scorlabs-ai.com`. It uses the supplied SCOR Labs mark and local system fonts, with no build step, external scripts, analytics, or CDN dependencies.

Serve this directory with any static HTTP server for preview. Production hosting must provide HTTPS. `_headers` is a deployment template for hosts that support that file format; other servers must configure equivalent response headers themselves.

Workspace calls to action currently lead to the capability and availability section. `platform.scorlabs-ai.com` is reserved for the persistent backend and is not yet open; enable direct workspace links only after deployment validation. The official site does not host account, credential, API, or private plugin functionality. The capability notice describes the current local evaluation boundary and must be updated only when actual validation supports it.

The supplied logo's image pixels are unchanged. The asset copy was checked for and stripped of PNG text/EXIF metadata chunks if present. No private project paths, release artifacts, or account data are included in the public site files.
